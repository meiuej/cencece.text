# CHENTERCE.TEXTS

## Состояние на 26 сентября 2026

Статический сайт без CMS. Главная ведёт на полноценную HTML-статью `dist/260926/index.html`, собранную по Figma и PDF. Страница адаптирована под телефон и компьютер. Репозиторий подключён к GitHub; публикация в GitHub Pages настроена через `.github/workflows/pages.yml`.

Открыть `dist/index.html` в браузере или из этой папки запустить `python3 -m http.server 4173 --bind 127.0.0.1 --directory dist`.

- Новый дизайн статьи — `/Users/timur/Downloads/аапппп.pdf` и Figma `eXRoiR7q6tiaDk1PBzPvTo`, фрейм `10:3`.
- Изображения новой статьи опубликованы в WebP. Крупные исходники уменьшены до 2000 px по ширине, остальные сохранены в размерах макета; изображения ниже первого экрана загружаются отложенно.

## Следующие шаги

1. Получить отзыв на страницу статьи.

CMS больше не планируется. Платных услуг нет, сторонней аналитики и внешних запросов шрифтов нет.

## Короткие адреса статей

Каждую новую статью размещать в `dist/<slug>/index.html`, где `slug` — от 1 до 6 строчных латинских букв или цифр. Использовать дату `ДДММГГ` (например, `260926`) или инициалы слов английского перевода заголовка. Перед публикацией проверять, что адрес свободен; для нескольких статей в один день выбирать разные буквенные сокращения. Не менять уже опубликованные короткие адреса.

Все ссылки на главной должны вести непосредственно на короткий адрес. Старый адрес `articles/youth-dissent/` оставлен только для перенаправления на `260926/`. Пути к ресурсам из статьи теперь начинаются с `../assets/`.

Проверка: `python3 chenterce/scripts/check_urls.py`. Эта же проверка запускается перед публикацией в GitHub Pages и отклоняет длинные адреса новых страниц. При создании статей сохранять блок `.support-card` после вступительных абзацев, непосредственно перед разделителем и заголовком «Публичные кейсы» и ссылку поддержки `https://donate.centerce.me/`.

## Единый стиль карточек источников и редакционных комментариев

Согласованный образец — белая прямоугольная карточка со скриншота пользователя от 27 сентября 2026 года. Этот стиль обязателен для ссылок на другие статьи (включая наши), источников и редакционных комментариев, например просьбы о поддержке.

- Использовать общий класс `.source-card`; для поддержки добавлять `.support-card`.
- Белый фон, чёрный текст, без цветной верхней полосы и скруглений.
- Подпись источника/дата или короткое вступление сверху, основной текст — крупный жирный Roboto Flex.
- Красная прямоугольная кнопка с белым текстом располагается ниже текста, слева; всё содержимое выравнивается по левому краю.
- На телефоне сохранять расположение, уменьшать отступы и шрифт.
- В блоке поддержки не использовать надпись «Независимость — с вашей поддержкой». Ставить его после вступления, перед верхним разделителем секции «Публичные кейсы».
