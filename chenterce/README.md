# CHENTERCE.TEXTS

## Состояние на 26 сентября 2026

Статический сайт без CMS. Главная ведёт на полноценную HTML-статью `dist/articles/youth-dissent/index.html`, собранную по Figma и PDF. Страница адаптирована под телефон и компьютер. Ничего не опубликовано в интернете: у репозитория пока нет remote, а GitHub CLI в среде отсутствует.

Открыть `dist/index.html` в браузере или из этой папки запустить `python3 -m http.server 4173 --bind 127.0.0.1 --directory dist`.

## Согласованное направление

- Независимое медиа о жизни в России, расследования и тексты, строгая журналистика.
- Только лента статей, без дополнительных сервисов.
- Один редактор/владелец, нужна закрытая система публикации с цитатами, изображениями, черновиками и предпросмотром.
- Шрифт: вариативный Roboto Flex (сохранён локально, лицензия OFL рядом).
- Цвета взяты из рендера пользовательского PDF: фон #121212, текст #FFFFFF, второстепенный текст #ACACAC, разделители #656565.
- Логотип пользователя — `dist/assets/logo.png`.
- Новый дизайн статьи — `/Users/timur/Downloads/аапппп.pdf` и Figma `eXRoiR7q6tiaDk1PBzPvTo`, фрейм `10:3`.
- Изображения новой статьи опубликованы в WebP. Крупные исходники уменьшены до 2000 px по ширине, остальные сохранены в размерах макета; изображения ниже первого экрана загружаются отложенно.
- Внешние ссылки: Meduza, ОВД-Инфо, внутренний материал на Medium и Telegram-канал «Гражданский круг».
- Общая навигация на главной и в статье содержит логотип и кнопку «Поддержать нашу работу» на `https://chenterce.info/centre-ts-donate.html`.
- Добавлены умеренные анимации появления и интерактивных состояний; они отключаются через `prefers-reduced-motion`.
- Главная показывает один материал, как запросил пользователь.

## Следующие шаги

1. Получить отзыв на страницу статьи.
2. При необходимости скорректировать интенсивность анимаций после просмотра на реальном устройстве.
3. После подключения собственного домена добавить его в настройках GitHub Pages.

CMS больше не планируется. Платных услуг нет, сторонней аналитики и внешних запросов шрифтов нет.
